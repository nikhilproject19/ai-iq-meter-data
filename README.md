# AI IQ Meter: live data

These files are read by the **AI IQ Meter** app while it is running. They are rebuilt automatically.

- `version.json`: which data is current and when it was last checked
- `data.json`: estimated scores, prices and facts for AI models
- `news.json`: recent AI headlines (headline, link, publisher and time only)

The IQ figures are estimates built from published test results. No AI sat a human IQ test.
